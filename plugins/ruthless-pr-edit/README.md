# ruthless-pr-edit

Writes or edits a pull request title and body by subtraction. The PR says *what* is
changing; the commits say *how* and the diff says *where*. Cut until only the
essential remains, then add back only what a reviewer would be wrong without.

Invoke with `/ruthless-pr-edit` when opening a PR, drafting or rewriting a
description, or tightening a body that has grown bloated.

## Skills

- `ruthless-pr-edit` — the method, with `examples.md` carrying the taste.
