# asd-ste100-concise

Writes English in ASD-STE100 Simplified Technical English — a controlled language
built so a reader who cannot ask a follow-up question reads the text one way only.
One meaning per word, active voice, simple tenses, short sentences, no narration.

Invoke with `/asd-ste100-concise`.

Never applies to code, quoted output, or text where exact wording carries the
meaning. Correctness has precedence over brevity.

## Skills

- `asd-ste100-concise` — the style rules, plus response-length rules.
